# 揽宝多数据源适配器说明

揽宝平台现已支持多种数据源适配器，用户可根据需要灵活配置数据源优先级，实现数据的自动fallback机制。

## 支持的数据源

| 数据源 | 适配器类 | 优先级 | 特点 | 使用场景 |
|-------|---------|--------|------|---------|
| **Tushare** | `TushareAdapter` | 1 | 高质量财经数据，接口稳定 | 历史数据分析、基本面研究 |
| **通达信(TDX)** | `TDXAdapter` | 2 | 实时行情快速，直连券商服务器 | 实时交易、高频行情获取 |
| **AkShare** | `AKShareAdapter` | 3 | 免费开源，数据丰富 | 免费数据获取、新闻舆情分析 |
| **MiniQMT** | `MiniQMTAdapter` | 1 | 实盘交易接口，tick级数据 | 实盘交易、量化策略执行 |

## 数据源优先级

优先级数字越小优先级越高。系统会按照优先级顺序尝试从各个数据源获取数据，如果高优先级数据源获取失败，则自动fallback到下一个数据源。

默认优先级：
- **MiniQMT**: 1 (实盘数据源，最高优先级)
- **Tushare**: 1 (高质量数据源)
- **通达信**: 2 (实时行情)
- **AkShare**: 3 (免费数据源，作为fallback)

## 配置方法

### 1. 环境变量配置

通过 `LANBAO_DATA_SOURCES` 环境变量配置启用的数据源：

```bash
# 启用Tushare和AkShare（默认）
export LANBAO_DATA_SOURCES="tushare,akshare"

# 启用所有数据源
export LANBAO_DATA_SOURCES="miniqmt,tushare,akshare,tdx"

# 仅启用通达信
export LANBAO_DATA_SOURCES="tdx"
```

### 2. Docker Compose 配置

在 `docker-compose.yml` 中配置：

```yaml
market-data:
  environment:
    - LANBAO_DATA_SOURCES=${LANBAO_DATA_SOURCES:-tushare,akshare}
    - TUSHARE_TOKEN=${TUSHARE_TOKEN}
    - QMT_PATH=${QMT_PATH}           # MiniQMT路径（如启用）
    - QMT_ACCOUNT_ID=${QMT_ACCOUNT_ID} # MiniQMT账号（如启用）
```

### 3. 代码中使用

```python
from lanbao_data import TushareAdapter, TDXAdapter, AKShareAdapter, MiniQMTAdapter

# 初始化适配器
tushare = TushareAdapter(api_token="your_token")
tdx = TDXAdapter(api_host="119.147.212.81", api_port=7709)
akshare = AKShareAdapter()
miniqmt = MiniQMTAdapter(qmt_path="/path/to/qmt", account_id="your_account")

# 获取数据（各适配器接口一致）
df = tushare.get_daily_data("000001.SZ", "20240101", "20241231")
df = tdx.get_daily_data("000001.SZ", "20240101", "20241231")
df = akshare.get_daily_data("000001.SZ", "20240101", "20241231")
df = miniqmt.get_daily_data("000001.SZ", "20240101", "20241231")
```

## 适配器接口说明

所有适配器都实现了统一接口：

### 基础方法

| 方法 | 说明 | 参数 | 返回值 |
|-----|------|-----|--------|
| `is_available()` | 检查数据源是否可用 | - | bool |
| `priority` | 数据源优先级 | - | int |

### 数据获取方法

| 方法 | 说明 | 参数 |
|-----|------|-----|
| `get_daily_data(symbol, start_date, end_date)` | 获取日线数据 | symbol: 股票代码, start_date: 开始日期(YYYYMMDD), end_date: 结束日期(YYYYMMDD) |
| `get_stock_list(market)` | 获取股票列表 | market: 市场类型 ('A', 'SH', 'SZ', 'BJ') |
| `get_realtime_quote(symbol)` | 获取实时行情 | symbol: 股票代码 |
| `get_index_data(index_code, start_date, end_date)` | 获取指数数据 | index_code: 指数代码 |

## 特有功能

### Tushare适配器
- 高质量的财务数据
- 实时新闻和公告
- 支持指数数据获取

### 通达信适配器
- 直接连接券商行情服务器
- 支持多服务器自动切换
- 5档实时行情
- 支持tick级数据获取

### AkShare适配器
- 完全免费
- 支持新闻舆情数据获取
- 支持资金流向数据
- 股票列表实时更新

### MiniQMT适配器
- 实盘交易接口
- tick级数据订阅
- 支持实时行情推送
- 交易执行功能

## 使用示例

### 多数据源fallback

```python
from lanbao_data import TushareAdapter, AKShareAdapter

# 初始化多个适配器
adapters = [
    TushareAdapter(),    # 优先级1
    AKShareAdapter(),    # 优先级3
]

# 按优先级获取数据
symbol = "000001.SZ"
for adapter in sorted(adapters, key=lambda x: x.priority):
    try:
        df = adapter.get_daily_data(symbol, "20240101", "20241231")
        if not df.empty:
            print(f"从 {type(adapter).__name__} 获取数据成功")
            break
    except Exception as e:
        print(f"{type(adapter).__name__} 获取失败: {e}")
```

### 实时行情对比

```python
from lanbao_data import TDXAdapter, AKShareAdapter

tdx = TDXAdapter()
akshare = AKShareAdapter()

symbol = "000001.SZ"

# 同时从多个数据源获取实时行情
tdx_quote = tdx.get_realtime_quote(symbol)
akshare_quote = akshare.get_realtime_quote(symbol)

print("通达信行情:", tdx_quote)
print("AkShare行情:", akshare_quote)
```

## 故障排除

### 常见问题

1. **Tushare API限制**
   - 免费用户有访问次数限制
   - 解决方法：升级会员或配置多个数据源fallback

2. **通达信连接失败**
   - 检查网络连接
   - 尝试不同的服务器地址
   - 确保防火墙允许连接

3. **MiniQMT初始化失败**
   - 检查QMT是否正确安装
   - 确认QMT_PATH环境变量设置正确
   - 确保已开通miniQMT权限

4. **AkShare数据更新延迟**
   - AkShare数据有延迟，适合非实时场景
   - 建议与Tushare或TDX配合使用

## 开发指南

### 添加新的数据源适配器

1. 在 `src/lanbao_data/lanbao_data/` 目录下创建新的适配器文件
2. 实现以下标准接口：
   - `__init__()` - 初始化适配器
   - `is_available()` - 检查可用性
   - `priority` - 优先级属性
   - `get_daily_data()` - 获取日线数据
   - `get_stock_list()` - 获取股票列表
   - `get_realtime_quote()` - 获取实时行情
   - `get_index_data()` - 获取指数数据

3. 在 `__init__.py` 中导出适配器类
4. 在 `market_data_node.py` 中注册适配器

### 示例

```python
class MyDataAdapter:
    def __init__(self):
        self._priority = 2
        
    @property
    def priority(self) -> int:
        return self._priority
    
    def is_available(self) -> bool:
        # 检查数据源是否可用
        return True
    
    def get_daily_data(self, symbol, start_date, end_date):
        # 实现数据获取逻辑
        pass
```
