    PAUSED --> RUNNING: 问题解决
    PAUSED --> STOPPED: 无法恢复

## 5. 熔断机制深度设计

### 5.1 多层次熔断状态机
```mermaid
stateDiagram-v2
    [*] --> CLOSED: 初始化
    CLOSED --> OPEN: 触发熔断条件
    OPEN --> HALF_OPEN: 超时时间到
    HALF_OPEN --> OPEN: 试探请求失败
    HALF_OPEN --> CLOSED: 试探请求成功
    
    state CLOSED {
        [*] --> IDLE
        IDLE --> PROCESSING: 请求到达
        PROCESSING --> SUCCESS: 处理成功
        PROCESSING --> FAILURE: 处理失败
        SUCCESS --> IDLE: 重置计数器
        FAILURE --> IDLE: 增加失败计数
    }
    
    state OPEN {
        [*] --> BLOCKING
        BLOCKING --> TIMEOUT_WAIT: 开始计时
        TIMEOUT_WAIT --> READY_FOR_TEST: 超时到达
    }
    
    state HALF_OPEN {
        [*] --> TEST_REQUEST
        TEST_REQUEST --> SUCCESS: 试探成功
        TEST_REQUEST --> FAILURE: 试探失败
    }
```

## 总结

揽宝系统V5.0在前期版本基础上实现了**架构级**的全面整合与优化，具备以下核心优势：
